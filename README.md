# 愤怒的小鸟 · 网页版

[![CI](https://github.com/939243423/angry-birds/actions/workflows/ci.yml/badge.svg)](https://github.com/939243423/angry-birds/actions/workflows/ci.yml)

零依赖、纯原生 JavaScript 实现的高品质愤怒的小鸟网页游戏，支持桌面端与移动端 H5，内置彩蛋关「蛋了个蛋」。

## 启动方式

- **桌面浏览器**：直接双击 `index.html` 即可运行（无需服务器）。
- **H5 / 手机访问**：将整个目录部署到任意静态服务器（推荐 `python -m http.server 8765`）。
- **依赖**：零。所有美术、贴图、音效全部用 Canvas + WebAudio 程序化生成，**完全离线可用**。

## 玩法亮点

### 主线关卡（10 关渐进式）
| 关卡 | 主题 | 引入机制 |
|------|------|---------|
| 1 | 初次试飞 | 基础弹弓 + 红/黄/蓝鸟 |
| 2 | 木石之塔 | 木块/石块材质 + 重力崩塌 |
| 3 | 烈焰引爆 | TNT 连锁爆炸 |
| 4 | 弹簧蹦床 | 弹簧板反弹 + 戴钢盔猪 |
| 5 | 空间传送 | 传送门（一进一出） |
| 6 | 气球猪与风 | 气球猪（悬浮）+ 风力影响 |
| 7 | 冰川裂隙 | 冰块（低摩擦）+ 多层支撑 |
| 8 | 末日要塞 | 国王猪 + TNT + 弹簧 + 风 综合 |
| 9 | 回旋峡谷 | 弹弓后方也有猪，必须用回旋绿折返打击 |
| 10 | 引力奇点 | 猪分散在三座独立高塔，适合引力紫聚拢后一网打尽 |

每关含 **3 颗星评分阈值**，通关后分数自动存档至 `localStorage`。

### 6 种小鸟技能
- 🔴 **烈焰红**：爆裂冲刺，撞击即炸
- 🟡 **闪电黄**：超音冲刺，穿透一切
- 🔵 **寒冰蓝**：分裂成 3 只，专破冰块
- ⚫ **爆破黑**：定时炸弹，大范围摧毁
- 🟢 **回旋绿**：折返飞行，回打身后的目标
- 🟣 **引力紫**：制造引力奇点，持续把周围刚体吸向中心

### 彩蛋关「蛋了个蛋」（隐藏内容）

**初始不在主菜单出现**——未解锁时界面上完全看不到它的痕迹（连金羽进度也一并隐藏）。

**解锁条件：在第 3 关拿到 2 星及以上。** 达成时触发解锁仪式：结算面板先播完星级动画 → 弹出解锁庆祝弹窗（大蛋弹入 + 摇晃 + 光爆，展示玩法与奖励）→ 关闭后回主菜单，彩蛋入口才带弹入动画登场。星数不足时会在结算面板明确提示还差几颗星。

玩法类似羊了个羊的堆叠三消：
- 棋盘上堆叠多类蛋卡，**7 格槽位**
- 槽中**同色累计 3 张**自动消除
- 槽满且无三连 = 失败；消除完所有蛋 = 胜利
- 道具：**移除底卡（最底层3张）/ 撤销上一步 / 打乱全部**
- 双难度：轻松 / 地狱
- 通关奖励：金羽（主菜单累计）

### 4 种猪
普通猪、小猪、戴钢盔猪、国王猪（带王冠）

### 4 种砖块材质
木、石、冰、TNT（含弹簧、传送门、风扇等机关）

### 实时信息提示
- **HUD**：关卡名 · 当前分数 · 风力等级（无风/东风/西风分级）· 剩余小鸟与**剩余猪数量**
- **暂停面板**：本关实时进度 —— 剩余猪、剩余鸟、当前分数、距下一颗星还差多少分
- **结算面板**：星级进度（距下一颗星还差多少分 / 已满星评价）、新纪录徽章
- **剩余小鸟队列**：在弹弓后方排队展示，数量多时间距与体型自动收缩，不会溢出画面

### 视觉特效
视差天空/远山/云朵、程序化角色绘制、粒子系统（爆炸/尘埃/星火）、屏幕震动、慢镜头时刻（最后一击）

### 音效
WebAudio 程序化合成：弹弓拉弓、撞击、爆炸、猪叫、过关星音效。**无任何外部音频文件**。

## H5 移动端深度适配
- 100dvh + JS 动态修正 `--vh`，解决 iOS Safari 工具栏遮挡
- `env(safe-area-inset-*)` 全局适配 iPhone 刘海/小白条
- 单指拖拽弹弓、双指缩放阻止、橡皮筋回弹阻止
- 移动端竖屏提示（横屏体验更佳）
- 触摸事件 + DPR 自适应 canvas 分辨率
- 防误触：双击放大阻止

## 操作

- **移动端**：单指拖拽小鸟→松开发射，飞行中**单指点击屏幕**触发技能

## 评分与进度

- 通关分数根据：剩余猪数 + 砖块破坏数 + 关卡倍率
- 完美通关（3 星）分数最高
- 最高分存档于 localStorage，重启浏览器不丢失
- 「清除存档」按钮在主菜单底部，可一键重置

## UI 设计系统

界面样式集中在 `css/style.css`，按「设计令牌 → 基础 → 组件 → 屏幕 → 响应式」组织。

### 设计令牌
颜色、圆角、阴影、动效时长统一在 `:root` 中定义，换主题只需改一处：

```css
:root {
  --amber-2:#ef8a26;      /* 主按钮填充 */
  --sun-2:#f6b955;        /* 次级按钮填充 */
  --ink-title:#7a3c12;    /* 面板标题字色 */
  --r-panel:clamp(16px,2.6vh,32px);
  --ease-pop:cubic-bezier(.2,1.5,.4,1);
}
```

### 流式缩放
全站尺寸采用 `clamp(下限, vh/vw, 上限)`，在 1600×900 与手机屏之间平滑过渡，无需逐档写断点。

### 无障碍
- 可交互元素统一支持 `:focus-visible` 键盘焦点环
- 遵循 `prefers-reduced-motion`：系统开启「减弱动效」时自动关闭动画
- 触控设备（`pointer: coarse`）自动保证 44px 最小触控目标

### 竖屏策略
游戏画面固定 16:9 水平铺满以保证不变形；**全屏面板则脱离舞台、铺满整个视口**，避免在竖屏窄条中被压扁裁切，并在顶部提示横屏体验更佳。

## 部署（Docker + Nginx）

对外端口 **3011**。

### 方式一：一键脚本（推荐）

把项目放到服务器上，在项目根目录执行：

```bash
chmod +x deploy.sh
./deploy.sh
```

脚本流程：拉取最新代码 → 构建并启动容器 → 等待服务就绪并自检 → 清理无用镜像。
自检失败会自动打印容器日志并退出（非 0 退出码）。

### 方式二：手动

```bash
docker compose up -d --build       # 构建并启动
docker logs -f angry_birds_3011    # 查看日志
docker compose down                # 停止
```

访问 `http://<服务器IP>:3011/`。

### 文件说明

| 文件 | 作用 |
|------|------|
| `Dockerfile` | 基于 `nginx:stable-alpine`，**白名单**只拷贝 `index.html` / `css/` / `js/` |
| `nginx.conf` | 站点配置：gzip、缓存分级、安全响应头 |
| `docker-compose.yml` | 端口映射 `3011:80`、日志轮转、异常自动重启 |
| `deploy.sh` | 一键部署脚本（含部署后自检） |
| `.dockerignore` | 缩小构建上下文，避免开发文件进入镜像 |

### 为什么不像素级缓存 CSS / JS？

`nginx.conf` 中 **HTML / CSS / JS 统一使用协商缓存**（`expires -1`），只有图片字体走 30 天强缓存。

因为本项目资源是固定文件名（`css/style.css`），**没有内容指纹**。若对 CSS/JS 使用长强缓存，
更新部署后老用户浏览器会持续命中旧缓存、看不到变化。协商缓存未修改时返回 304，开销可忽略。

### 部署注意

- **存档按「协议 + 域名 + 端口」隔离**：游戏进度存在浏览器 `localStorage`。
  从 `localhost:8765` 换到 `IP:3011` 访问时进度会重新开始，属正常现象。
- 服务器防火墙 / 云安全组需放行 **3011** 端口。
- 已通过 `git update-index --chmod=+x` 为 `deploy.sh` 标记可执行位，服务器上 clone 后可直接 `./deploy.sh`。
