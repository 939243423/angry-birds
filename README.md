# 愤怒的小鸟 · 网页版

[![CI](https://github.com/939243423/angry-birds/actions/workflows/ci.yml/badge.svg)](https://github.com/939243423/angry-birds/actions/workflows/ci.yml)

零依赖、纯原生 JavaScript 实现的高品质愤怒的小鸟网页游戏，支持桌面端与移动端 H5，内置彩蛋关「蛋了个蛋」。

## 启动方式

- **桌面浏览器**：直接双击 `index.html` 即可运行（无需服务器）。
- **H5 / 手机访问**：将整个目录部署到任意静态服务器（推荐 `python -m http.server 8765`）。
- **依赖**：零。所有美术、贴图、音效全部用 Canvas + WebAudio 程序化生成，**完全离线可用**。

## 玩法亮点

### 主线关卡（8 关渐进式）
| 关卡 | 主题 | 引入机制 |
|------|------|---------|
| 1 | 初次试飞 | 基础弹弓 + 红/黄/蓝鸟 |
| 2 | 木石之塔 | 木块/石块材质 + 重力崩塌 |
| 3 | 烈焰引爆 | TNT 连锁爆炸 |
| 4 | 弹簧蹦床 | 弹簧板反弹 + 戴钢盔猪 |
| 5 | 空间传送 | 传送门（一进一出） |
| 6 | 气球猪与风 | 气球猪（悬浮）+ 风力影响 |
| 7 | 冰川裂隙 | 冰块（低摩擦）+ 多层支撑 |
| 8 | 末日要塞 | 国王猪 + TNT + 弹簧 + 风 综合 |

每关含 **3 颗星评分阈值**，通关后分数自动存档至 `localStorage`。

### 4 种小鸟技能
- 🔴 **红鸟**：标准威力
- 🟡 **黄鸟**：空中加速冲刺
- 🔵 **蓝鸟**：分裂成 3 只
- ⚫ **黑鸟**：爆炸冲击波

### 彩蛋关「蛋了个蛋」
通关第 3 关后解锁。类似羊了个羊的堆叠三消：
- 棋盘上堆叠多类蛋卡，**7 格槽位**
- 槽中**同色累计 3 张**自动消除
- 槽满且无三连 = 失败；消除完所有蛋 = 胜利
- 道具：**移除底卡（最底层3张）/ 撤销上一步 / 打乱全部**
- 双难度：轻松 / 地狱
- 通关奖励：金羽（主菜单累计）

### 4 种猪
普通猪、小猪、戴钢盔猪、国王猪（带王冠）

### 4 种砖块材质
木、石、冰、TNT（含弹簧、传送门、风扇等机关）

### 视觉特效
视差天空/远山/云朵、程序化角色绘制、粒子系统（爆炸/尘埃/星火）、屏幕震动、慢镜头时刻（最后一击）

### 音效
WebAudio 程序化合成：弹弓拉弓、撞击、爆炸、猪叫、过关星音效。**无任何外部音频文件**。

## H5 移动端深度适配
- 100dvh + JS 动态修正 `--vh`，解决 iOS Safari 工具栏遮挡
- `env(safe-area-inset-*)` 全局适配 iPhone 刘海/小白条
- 单指拖拽弹弓、双指缩放阻止、橡皮筋回弹阻止
- 移动端竖屏提示（横屏体验更佳）
- 触摸事件 + DPR 自适应 canvas 分辨率
- 防误触：双击放大阻止

## 操作

- **桌面端**：鼠标按住小鸟→拖拽→松开发射，飞行中**点击鼠标**触发技能
- **移动端**：单指拖拽小鸟→松开发射，飞行中**单指点击屏幕**触发技能
- 右上角可静音，暂停可在游戏内按暂停按钮或 `Esc`

## 评分与进度

- 通关分数根据：剩余猪数 + 砖块破坏数 + 关卡倍率
- 完美通关（3 星）分数最高
- 最高分存档于 localStorage，重启浏览器不丢失
- 「清除存档」按钮在主菜单底部，可一键重置

## UI 设计系统

界面样式集中在 `css/style.css`，按「设计令牌 → 基础 → 组件 → 屏幕 → 响应式」组织。

### 设计令牌
颜色、圆角、阴影、动效时长统一在 `:root` 中定义，换主题只需改一处：

```css
:root {
  --amber-2:#ef8a26;      /* 主按钮填充 */
  --sun-2:#f6b955;        /* 次级按钮填充 */
  --ink-title:#7a3c12;    /* 面板标题字色 */
  --r-panel:clamp(16px,2.6vh,32px);
  --ease-pop:cubic-bezier(.2,1.5,.4,1);
}
```

### 流式缩放
全站尺寸采用 `clamp(下限, vh/vw, 上限)`，在 1600×900 与手机屏之间平滑过渡，无需逐档写断点。

### 无障碍
- 可交互元素统一支持 `:focus-visible` 键盘焦点环
- 遵循 `prefers-reduced-motion`：系统开启「减弱动效」时自动关闭动画
- 触控设备（`pointer: coarse`）自动保证 44px 最小触控目标

### 竖屏策略
游戏画面固定 16:9 水平铺满以保证不变形；**全屏面板则脱离舞台、铺满整个视口**，避免在竖屏窄条中被压扁裁切，并在顶部提示横屏体验更佳。

### CI 自动校验

每次 push / PR 到 `main` 会触发 GitHub Actions（`.github/workflows/ci.yml`）：

1. 全部 JS 语法检查（`node --check`）
2. 冒烟自检（`node tools/smoke.js`）
3. 关键文件存在性与非空校验

本地推送前建议先跑一遍 `node tools/smoke.js`，与 CI 保持一致。
